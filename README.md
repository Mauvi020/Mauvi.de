# Info.Mauvi.de 🕹️
> My own retro linktree & info website.

I wanted a personal linktree website, so I coded this entire project myself from scratch using **HTML, CSS, and JavaScript**. 

The goal was to avoid a boring, generic corporate look. This site has a real, custom vintage aesthetic that I styled exactly the way I wanted.

---

## 🚀 Features

* **3-Column Retro Layout:** Links on the left, Blog in the middle, Widgets on the right.
* **Custom Theme:** A dark retro-red design with gold/yellow text and spacious boxes.
* **Auto Language Check:** Detects the visitor's browser language (German/English) and switches automatically.
* **Live MC Status:** A custom script that pings `mauvi.de` live to show if the server is online and how many players are on it.
